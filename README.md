# ItalBridge Management Simulation

Static site for the executive business game.

## Entry points

- `index.html` → welcome page
- `settings.html` → facilitator-only mandate setup
- `game.html` → game flow
- `epilogo.html` → closing page

## Notes

- Mandates are stored in `localStorage`.
- The same browser/device must be used for `settings.html` and `game.html`.
